# Wymagania UZP i pytania do mentora

Audyt z 21.11.2026 przypięty do commita UZP `de135d20811caf630f3e94dc655ba5eebd9a6710`.

FAQ 1.0 przekazane przez użytkownika doprecyzowuje wymagania dla zgłoszenia: model i komponenty open source, możliwość lokalnej instalacji modelu oraz brak ograniczeń użytkowania i opłat licencyjnych. Przy wykorzystaniu API zarówno usługodawca, jak i serwer mają znajdować się w UE; FAQ wymaga przekazania klucza organizatorowi. Obejmuje to ostrzejszy obszar geograficzny niż wcześniejsze sformułowanie UE/EOG. Opłaty licencyjne modelu i opłaty za użycie API należy sprawdzać osobno. Dane FAQ pochodzą z treści przekazanej w rozmowie; nie potwierdzono tu niezależnie publikacji FAQ.

FAQ wymaga CLI z instrukcją, trzech klas, obsługi skanów i wartości `null`, gdy schemat na to pozwala. GUI jest dodatkowo punktowane, a preferowany układ pokazuje PDF i dane obok siebie. Rozszerzanie klas i pól przez konfigurację jest szczególnie istotne w finale. Przygotowanie pełnego systemu obsługi postępowań nie jest wymagane.

| U01 | Czy pusty wynik ma 0 bajtów, czy zawiera `{}`? | Domyślnie 0 bajtów (`empty_file`). `--negative-output empty_object` zapisuje `{}`. | Backend |
| U02 | Jak scorer liczy F1 dla `null`, pustych napisów, braków, list i duplikatów? | Lokalny micro-F1 według [planu integracji](INTEGRATION_PLAN.md). Uznaj go za metrykę zespołu. | Backend |
| U03 | Który opis obowiązuje dla ID 6 oraz czy w ID 12 interpunkcja jest oceniana? | Prompt dostaje dokładne etykiety z opublikowanego słownika, bez końcowej kropki dla ID 12. Pięć złotych opisów dla ID 6 odbiega od słownika. | Backend |
| U04 | Jak reprezentować brak pierwszego zarzutu, brak typu mocodawcy i nieustalone umocowanie? Czy `pelnomocnik` pozostaje obiektem z pustymi polami? | Roboczo `null` dla nieustalonego skalara, `[]` dla pustej listy, obiekt z pełnym zestawem kluczy. Jawne 0/1 na podstawie treści. Potwierdzić przed wydaniem. | Backend |
| U05 | Czy PESEL to liczba, czy napis zachowujący 11 cyfr? | Wzorzec podaje liczbę. W treningu 97 wartości to `null`, a jedna to 11-cyfrowy napis. Prompt wymaga rozpoznania 11 cyfr i stosuje roboczy kontrakt `integer` lub `null` przy serializacji. | Backend |
| U06 | Jak bezpiecznie dostarczyć klucz organizatorowi i potwierdzić lokalizację usługodawcy oraz serwera w UE? | Kandydat Mistral: karty Ministral 3 8B/14B podają Apache 2.0 i wagi do instalacji lokalnej; dostawcą jest francuska Mistral AI, a `api.eu.mistral.ai` kieruje inferencję do UE/EFTA. Producent zaznacza, że metadane konta/rozliczeń mogą być przetwarzane poza regionem. FAQ mówi o UE, więc potwierdzić, czy rozproszenie UE/EFTA spełnia literalny warunek, oraz uzgodnić hostowane API i retencję przed użyciem wrażliwych danych. | Backend / zespół |
| U07 | Czy błędny PDF albo niedostępny OCR wymaga pliku wynikowego? | CLI zgłasza błąd, kontynuuje batch i zwraca kod 1. Przy ponowieniu wcześniejszy wynik pozostaje na dysku. Przy odbiorze uruchamiać na świeżym `output/`. | Backend |
| U08 | Czy organizator zapewni uczestnikom bezpłatny klucz lub kredyty do API otwartego modelu spełniającego wymagania firmy i serwerów UE? Jakie modele i limity będą dostępne podczas oceny? | Oba modele są dostępne pod endpointem UE, ale podany klucz otrzymał HTTP 429 także przy minimalnym żądaniu. Pełny benchmark 8B/14B nie ma wyniku. Sprawdzić stan i limity organizacji w konsoli Mistral; potwierdzić od organizatora klucz/kredyty na finał. | Zespół / mentor |

Dobór `pypdf`, JSON Schema, YAML, OCR, strategii ekstrakcji i struktury modułów to decyzje zespołu. BZP i TED mają odrębne pola. Komentarz wzorca BZP używa przykładu ze spacją oraz polecenia usunięcia spacji. Backend porównuje format z danymi przed finalizacją normalizacji.

Organizator doprecyzował, że imiona i nazwiska mają być w mianowniku. Wymóg obowiązuje wszystkie role w polach `imie_nazwisko`. Organizator opublikował też 30 par skanów i referencyjnych JSON, po 10 na klasę. W trzech referencyjnych pełnomocnictwach cztery wartości `pesel` są napisami, co pozostaje częścią pytania U05.
